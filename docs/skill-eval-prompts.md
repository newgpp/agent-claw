# Skill Evaluation Prompts

下面这 6 个问题用于测试新增的 3 个 Tavily skill 的效果和 token 消耗。

建议记录以下信息：
- 用户输入
- final_answer 质量
- planner / executor / total token
- 是否命中了预期 skill

## trend-research

1. 查询最近三天 AI Agent 方向最值得关注的 5 条进展，优先看 OpenAI、Anthropic、Google DeepMind、xAI 和 LangChain，按“发布时间 + 来源 + 一句话影响”输出。

2. 帮我看下最近一周 X 上关于 Manus、OpenAI Agents SDK、Browser Use 这几个话题的讨论热点，总结出 5 个高频观点和 3 个争议点。

## market-intel

3. 查询英伟达最近 7 天的新闻和股价变动，帮我总结“发生了什么、为什么涨跌、市场怎么看”。

4. 查询特斯拉最近两周的重要新闻，并结合股价表现，整理一个简短事件时间线。

## job-search-cn

5. 帮我找上海地区最近发布的 AI Agent 产品经理岗位，优先看 BOSS 直聘，整理岗位名称、公司、薪资范围和核心要求。

6. 查询北京最近一周发布的大模型应用工程师岗位，优先看 BOSS 直聘和主流招聘站，输出 10 个职位样本。
